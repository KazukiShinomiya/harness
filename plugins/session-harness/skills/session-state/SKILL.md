# SESSION_STATE.md の更新

プロジェクトルートの `SESSION_STATE.md` を、次のセッションが読んで即座に作業へ戻れる状態に保つ。
このファイルは次回の SessionStart で自動的に文脈へ注入される。

## フォーマット

```markdown
# SESSION_STATE

最終更新: YYYY-MM-DD

## 現在の状況

## 前回の戦果

## 次の行動

## 決定事項・メモ
```

## 原則

- **軽量に保つ。** 全履歴の記録場所ではない。git log で追えることは書かない。
- 相対日付（「昨日」「先週」）は絶対日付へ変換して書く。
- 未検証の推測を戦果として書かない。実際に確認できたことだけを書く。
- 次の行動は、読んだ人がそのまま着手できる粒度にする。
